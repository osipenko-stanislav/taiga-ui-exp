Маппинг цветов Taiga → OTUS

Подключено к теме · {{ total }} семантических токенов · 4 школы · светлая и тёмная темы

Надстройка OTUS над Taiga: сохраняются её роли, состояния и обращения --tui-* в компонентах. Значения берутся из существующей палитры Otus global colors. В исходной схеме primary общий для школ, различается школьный акцент. Редактор сохраняет локальный черновик; исходники библиотеки меняются только после переноса настроек в проект.

Как читать таблицу и подключать маппинг

Слева — базовые объявления TUI до маппинга, справа — подключённые токены OTUS и цвет с учётом прозрачности. Тема в панели Storybook переключает light/dark, выбор школы подсвечивает её колонку. Школы сравниваются одновременно.

Исходная схема. Единственный источник цветов — Otus global colors . Primary и действия: graphite-black-925 (#131315) для всех школ; в тёмной теме — graphite-black-50 (#E9EAEA). Существующий accent-2 связан с expert-blue для university, sure-blue для tech, care-violet для design и education-green для nature.

Коммуникационный гайд Figma используется только как контекст. Цвета из него не добавляются. Тема экспериментальная. Контраст рассчитан для перечисленных ниже пар; для других сочетаний и графиков нужна отдельная проверка. Архитектура и поведение Taiga сохраняются.

JSON содержит обе темы, все школы, исходную палитру, CSS-выражения, основания выбора и ручные настройки configuration.overrides при наличии черновика. Экспорт всегда полный и не зависит от поиска. В общей теме уже объявлены переменные OTUS и алиасы TUI. Школа задаётся атрибутом data-brand , тема — tuiTheme на том же контейнере. Дочерние компоненты и порталы наследуют значения. 

/* Слой OTUS после темы Taiga */
--otus-color-graphite-black-graphite-black-925: #131315;
--tui-background-accent-1: var(--otus-color-graphite-black-graphite-black-925);
--tui-background-accent-2: var(--otus-color-brand-expert-blue-expert-blue-700);

Таблица охватывает цветовые переопределения проекта из palette.less, включая графики. Токены, определённые только во внешней палитре Taiga, не включены. Источник палитры и генератор алиасов находятся в пакете styles.

WCAG 2.2 AA, 1.4.3 : обычный текст — минимум 4,5:1. Проверяются default/hover/pressed на базовом фоне темы с учётом прозрачности. Вердикт рассчитывается до округления. Primary и accent: hover светлее базового, pressed темнее — как в Taiga. Это правило исходной схемы. После ручных изменений проверьте также различимость default, hover и pressed.

Для университета выбрана тройка expert-blue-700 → 600 → 800: исходный #775AFF не даёт 4,5:1 ни с белым, ни с самым тёмным цветом OTUS. В checked negative тёмной темы расчёт включает локальный алиас --tui-status-negative → service/red/red-700. Он описан в JSON contextOverrides и использует существующий checked-селектор Taiga.

Это проверка перечисленных сочетаний, а не всей доступности компонентов. Состояния с CSS-фильтрами (primary-destructive), изображения, произвольные фоны, индикаторы фокуса и нетекстовый контраст не проверены.
